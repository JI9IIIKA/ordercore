# Проверка самостоятельного репозитория

После отделения от исходного набора: сборка всех локальных пакетов, go vet и модульные тесты успешно проверены заново. Интеграционный сценарий сохранён только для этого проекта.

Исходная версия прошла API+SQL тесты на PGlite с одним соединением. Такой прогон не доказывает корректность настоящей многосессионной конкуренции PostgreSQL. В CI настроен PostgreSQL 17; CI на вашем GitHub ещё не запускался.

Docker daemon, Kubernetes, живые брокеры/Redis/ClickHouse, gRPC end-to-end и AI-вызовы в этой среде не проверены. Подготовленные конфигурации не следует считать успешно развёрнутыми интеграциями. Дополнительные возможности первоначальной идеи перечислены в README внутри projects.

После разделения также повторно успешно выполнен API+SQL сценарий этого репозитория на PGlite (одно соединение, default_query_exec_mode=exec). Полноценный PostgreSQL 17 в этом прогоне не использовался.
